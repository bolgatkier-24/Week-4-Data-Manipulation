PostgreSQL SQL Assignment

This assignment contains SQL queries demonstrating the use of aggregation functions, grouping, sorting, and limiting results in PostgreSQL.

Questions Covered
Question 1: Calculates the total payment amount for each payment date and displays the 5 latest payment dates.
Question 2: Calculates the average credit limit for each customer, grouped by customer name and country.
Question 3: Calculates the total price of products ordered using quantity ordered and price per unit.
Question 4: Finds the highest payment amount for each check number.

# SQL Concepts Used
SELECT
SUM()
AVG()
MAX()
GROUP BY
ORDER BY
LIMIT
Arithmetic expressions
